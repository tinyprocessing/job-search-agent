# Your CV goes here (git ignores everything in this folder except this file)

- `cv.pdf` — the CV you send today.
- `cv.md` — the same CV as text. `setup` creates it from the PDF; it is the only source of facts the agent may use.

Adapted versions for each application are saved in `applications/<company>-<role>/`
(`cv.md` + `cv.html`; open the HTML in a browser → Print → Save as PDF).
